# mi-priemra-web

Guía en español sobre cómo hacer SEO, publicada en https://como-hacer-seo.netlify.app

- `index.html`: la guía (incluye el código de Google AdSense).
- `privacidad.html`: política de privacidad y cookies.
- `ads.txt`, `robots.txt`, `sitemap.xml`: archivos para AdSense y buscadores.
