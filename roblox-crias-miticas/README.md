# Crías Míticas (Mythic Hatchlings)

## Probarlo en Roblox Studio

1. Descarga el lugar: `https://github.com/candhu23/mi-priemra-web/raw/claude/confident-johnson-v5zy5f/roblox-crias-miticas/MythicHatchlings.rbxl`
2. Ábrelo con doble clic (se abre Roblox Studio).
3. Pulsa **Play** (▶ arriba). Tus crías te siguen y rompen solas los cristales cercanos (botón
   «🎯 Auto»), o toca un cristal para mandarlas. Camina hasta el huevo grande (aro dorado) y pulsa «Abrir».
   En «🐾 Crías» equipas las mejores y fusionas 5 iguales (3 desde Prodigiosa) en el altar. Los puentes tienen una puerta: ahí abres la isla siguiente.
4. Sin publicar, el juego avisa de que **no guarda**: es normal.

## Publicarlo por primera vez

1. En Studio: **File → Publish to Roblox As…** → **Create new experience**.
2. Nombre: *Mythic Hatchlings* · Género y dispositivos: todos.
3. Después: Creator Hub → la experiencia → **Settings → Security → Enable Studio Access to API Services**.
4. Dile a Claude el **Universe ID** y el **Place ID** (Creator Hub → ⋯ → Copy Universe ID) para que
   pueda publicar las siguientes versiones por ti.
